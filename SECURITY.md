# Security Policy

## Supported Versions

Privacy Guard actively maintains security and protocol compatibility for the latest released versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.9.x   | :white_check_mark: |
| 0.8.x   | :x:                |
| < 0.8.0 | :x:                |

---

## Reporting a Vulnerability

We take the security and privacy of Privacy Guard users very seriously.

If you discover a security vulnerability or a privacy leak (e.g., unexpected data leakage over a new Meta endpoint, protocol bypass, or permission elevation):

1. **Please do NOT disclose it publicly** in an open GitHub issue.
2. Submit a report via GitHub Private Vulnerability Reporting or email the maintainer directly.
3. Include detailed reproduction steps, network traces, and browser environment information.

### What to Expect
- You will receive an acknowledgment within 48 hours.
- We will provide a timeline for triage and patch deployment.
- Once a fix is released, you will be credited in the release notes (unless you prefer to remain anonymous).
